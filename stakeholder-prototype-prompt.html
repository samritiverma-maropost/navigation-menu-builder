I'm building a clickable prototype of a navigation menu builder for stakeholder
review — not production code. Use React + Tailwind, single project, client-side
state only.

Pull design references from the connected Figma file (key: 5Dd6KVq8SSMgZiwzPk4rsE,
board node 11100:44617) via the Figma MCP connection. Match colors, spacing, and
typography from these frames — don't restyle:

- "Listing page" — navigation menus table with status pills and a "Create a menu" button.
- "New Menu editor page" — empty state before any items are added, single "Add new" button.
- "Add new menu" / "Add new menu 2" — the create flow: Menu Name field, Active
  toggle, Preview/Cancel/Save.
- "Select Resource type" — dropdown with these exact options: Custom URL,
  Collection, Category, Home page, Pages, Blogs, Search, Products.
- "Custome URL" — when Resource type = Custom URL, show an editable "Link to"
  text field.
- "Resource type: category" / "Select Nested Category" / "Open Nested Category" —
  when Resource type = Category or Collection, instead of a text field, show a
  read-only "Linked Resources" field plus a "Change Selection" button that opens
  the nested collection picker (checkboxes, expand/collapse chevrons, color-coded
  L1/L2/L3 level pills, sort dropdown, search, "Apply to menu" button).
- "Resource type pages list" / "Resource type blogs list" — same nested-picker
  pattern for Pages and Blogs.
- "Image Source: Collection" / "Custom" / "None" — three-way toggle on the item
  details panel with a contextual note box that changes per option.
- "Hide Menu" / "Actions" — item details panel has "Hide on storefront" and
  "Remove from menu" as two distinct actions.
- "Bulk action idea 1" — when one or more tree rows are checked, a dark toolbar
  appears above the list showing "N selected" with Hide / Remove / Clear buttons.
  The header row gets an indeterminate checkbox when some but not all rows are
  selected.
- "Filter page" — sort/filter control on the menu structure list ("New → Old"
  dropdown).

Wire up real interaction, not just visuals:
- Checking a checkbox in the tree checks its ancestors up to L1; unchecking a
  parent unchecks everything nested under it.
- The "Include children" toggle only appears on rows that have children.
- Selecting rows in the main tree shows the bulk action toolbar; Hide/Remove/Clear
  act on the checked set and then it disappears.
- Clicking a row in the tree populates the Item Details panel on the right for
  that item.

Keep all state in React (useState/useReducer) — nothing needs to persist after
a refresh, this is for click-through review only.
